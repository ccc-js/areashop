# 統一模式（取代 v0.1 商品流 ＋ v0.2 預約流的兩分法）

賣東西和賣服務是同一種，不分兩類。賣東西有營業時段，面交有營業時段，服務也有——全部走同一套。

## 一種項目（`items`）

| 賣法 | `stock` | `bookable` |
|------|---------|------------|
| 賣東西（賣完為止） | 有值 | 關 |
| 賣服務（不限量＋選日期） | NULL | 開＋設可接案時間 |
| 混合（如下單買＋預約某天取） | 有值 | 開 |

## 一種訂單（`orders`）

- `date`/`window` 為空＝直接買；有值＝選日期的單。
- 狀態機統一：`pending → confirmed → ready → completed ｜ cancelled ｜ noshow`（confirmed 可跳過 ready 直接 complete；noshow 限店主）。
- 有庫存才扣庫存、取消才回補；不限量（`stock` NULL）不檢查數量。
- 同單限同店；同買家同項目同日只留一筆有效單；有日期的單才有取消期限（`cancel_hours`）。

## 可接案時間（只給 `bookable` 用）

- 週範本（每天開關＋自填時段，可多段；24 小時就寫 `00:00-24:00`）＋ 單日例外（正常接／額滿／不營業）。
- 可約 ⇔ 範本有開且沒被勾額滿／不營業。人數不進系統（很多買家不走系統，算不準）。

## Breaking

舊 `products`/`services`/`appointments` 表直接廢棄不遷移，程式也不再讀寫。改版後現有開發 DB 一律 `./run.sh --reseed`。
