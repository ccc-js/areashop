## 2. 實際交付

### 後端
- `routes/uploads.rs`（新）：`upload_dir()` 吃 `UPLOAD_DIR` env（預設 `./uploads`，test.sh 指到 tmp 隔離）；檔名 `{uuid}.{ext}`；空請求／超量／超檔數全 400。
- `entities/notification.rs`＋`routes/notifications.rs`（新）：`list`（本人倒序 50）、`unread-count`、`read`（空 ids＝全讀）；`push()` 工具給 orders 用。
- `orders.rs`：下單後通知店主；轉單後通知對方（店主動→買家，買家取消→店主；自己買自己不擾民）。

- 依賴只加一個：`axum` 開 `multipart` feature；不加圖片處理 crate（原圖直存，CSS 縮圖）。

### 前端

- i18n：`notif.*`（7 種文案三語）、`shop.*`、`seller.photos*`、`nav.notif`。

## 3. 刻意簡化

1. 原圖直存不壓縮；大圖靠 CSS `object-fit: cover` 顯示。流量起來再加壓縮。
2. 通知純輪詢無 push；已讀狀態不影響訂單邏輯。
3. 種子不帶圖（沒現成檔案）；DEMO 要圖請手動上兩張。
4. 圖片更新只能整包覆寫（`PATCH /items/:id {images}`），Seller 暫不提供編輯圖（下架重上即可）。

## 4. 已知限制 / 技術債

- `uploads/` 本機目錄：多機部署要換 S3（路徑寫死相對目錄，換的時候改 `upload_dir()` 一處即可）。
- 刪項目不會刪圖檔（孤兒檔會累積；要清得另寫 GC）。
- 通知表無上限增長；以後加 retention（只留 90 天）或分頁。
