## 2. 實際交付

### 後端（Axum + SeaORM，`backend/src/`）
- 新增 `search.rs`（純函數＋單元測試，不依賴 DB 方言）：
  - 正規化：轉小寫、全形轉半形（`９`→`9`、`，`→`,`）、去空白與中英標點。
  - 切 token：ASCII 按非字母數字切詞；CJK（中日韓＋假名諺文）逐字成 token；去重保序。
  - 匹配：query 全部 token 都出現在（標題＋描述）才算中（AND）。例：「水餃 20顆」→水/餃/20/顆；「Poke Bowl」→poke/bowl。
- `items.category` 新欄：entity 加 `String`；舊庫啟動時 `ALTER TABLE ADD COLUMN` 補（`NOT NULL DEFAULT 'other'`，SQLite/PG 通用，實測舊庫重開正常）。
- `POST /items`（預設 `other`，白名單外 400）、`PATCH /items/:id`（可改分類）、`GET /items` 加 `category=` DB 層過濾＋ `q` 改走分詞（標題＋描述，以前只比標題子字串）。

### 種子
- 23 個項目全部分類（雞鴨蛋菜→`fresh`、水餃牛肉→`food`、寄養快剪掛號→`service`）；加法冪等，`category` 是建表時新欄所以新舊庫都有（舊庫補預設 `other`，建議 `--reseed` 讓分類正確）。

### 工具鏈
